Статический веб-сайт, созданный в ходе выполнения лабораторной работы по настройке автоматического развёртывания (CI/CD) веб-проекта на хостинге с использованием GitHub Actions.

Цель работы
Получение практических навыков настройки автоматического развёртывания (CI/CD) веб-проекта на хостинге с использованием сервиса GitHub Actions.

Задачи
Создать репозиторий проекта на GitHub с файлами статического веб-сайта.

Опубликовать сайт на хостинге (GitHub Pages).

Разработать workflow-файл GitHub Actions, автоматически запускающий сборку и развёртывание проекта при каждом push в репозиторий.

Убедиться, что изменение файлов в репозитории приводит к автоматическому обновлению сайта на хостинге без ручных действий.

Реализовать индивидуальный проект с применением настроенного CI/CD-пайплайна.

Используемые технологии
HTML5, CSS3 — статический сайт.

GitHub — хранение репозитория и исходного кода.

GitHub Pages — хостинг статического сайта.

GitHub Actions — CI/CD-пайплайн для автоматической сборки и деплоя.
